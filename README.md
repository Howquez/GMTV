# Testing the Robustness and Generalizability of Dynamic Public Good Games

This repository contains the experimental materials, data, and analysis code for the paper "A comment on 'growth and inequality in public good provision': Testing the robustness and generalizability of dynamic public good games" published in the Journal of Behavioral and Experimental Economics .

## Repository Structure

- `_revision/`: Contains the most recent analyses and final version of the paper, implemented using a literate programming approach in Quarto that combines the manuscript text and analysis code
- `otreeLite/`: Contains the oTree implementation of the experimental design
